# Участие в разработке DevReport

Спасибо за интерес к проекту.

## Окружение

1. Установите Python 3.11+.
2. Создайте виртуальное окружение и установите пакет с dev-зависимостями (см. README).
3. Перед отправкой изменений запускайте:

```text
ruff check src tests
ruff format src tests
mypy
pytest
```

## Принципы

- Безопасность и приватность важнее удобства сбора данных.
- Не добавляйте сетевую отправку, телеметрию или чтение секретов из домашних каталогов.
- Runtime-зависимости держите минимальными.
- Сообщения CLI/README — на русском; идентификаторы API и machine codes — на английском.
- Тесты не должны требовать Docker, интернет или права администратора.

## Структура

Исходники в `src/devreport/`, тесты в `tests/`. Соблюдайте разделение: collectors / checks / redaction / renderers / cli.
