# DevReport

**Язык:** **Русский** | [English](README.en.md)

DevReport — небольшая кроссплатформенная CLI-утилита для подготовки диагностических отчётов о локальном окружении проекта (Windows и Linux).

Типичный сценарий: открыть терминал в каталоге проекта → `devreport collect` → получить краткую диагностику → при необходимости явно добавить лог → проверить предупреждения о чувствительных данных → приложить Markdown-отчёт к Issue или отправить коллеге.

Это **не** сканер уязвимостей, **не** автопочинка и **не** сервис с облаком/телеметрией.

## Ограничения MVP

- Только явно запрошенный лог (`--log`); без флага логи не читаются.
- Значения `.env` никогда не попадают в отчёт (сравниваются только имена ключей).
- Docker daemon не проверяется (`docker ps` / `docker info` не вызываются).
- Порт проверяется только на `127.0.0.1` (IPv4); IPv6 не проверяется.
- Multiline и сложный синтаксис dotenv поддерживаются ограниченно.
- Автоматическое маскирование **неполное**: не удаляет все секреты (нестандартные ключи, свободный текст) — обязательно проверьте отчёт вручную перед публикацией.
- Команды из директории проверяемого проекта не выполняются.
- Поддержка заявлена для Windows 10/11 и Linux.

## Установка из локального checkout

Требуется Python 3.11+.

### Windows (PowerShell)

```powershell
cd d:\projects\DevReport
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -e ".[dev]"
```

### Linux (bash)

```bash
cd /path/to/DevReport
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -e ".[dev]"
```

Запуск:

```text
devreport --help
python -m devreport --help
```

Установка пакета с PyPI в этом README **не** описана как гарантированный способ: публикуйте/устанавливайте из исходников checkout.

## Параметры `collect`

| Параметр | По умолчанию | Описание |
| --- | --- | --- |
| `--project` | текущая директория | Корень проекта |
| `--port` | не задан | Bind-проверка TCP на 127.0.0.1 |
| `--log` | не задан | Явно добавить хвост лог-файла |
| `--tail` | 50 (или из конфига) | Число строк лога (1–1000) |
| `--format` | markdown | `markdown` или `json` |
| `--output` / `-o` | нет | Записать отчёт в файл |
| `--preview` | false | Показать отчёт без записи файла |
| `--force` | false | Перезаписать существующий `--output` |

Без `--output` полный отчёт идёт в **stdout**, краткая сводка и предупреждения — в **stderr**.  
`--preview` и `--output` вместе — ошибка аргументов.

Конфигурация проекта: `.devreport.toml` в корне (CLI > конфиг > встроенные значения).

## Примеры

```text
devreport collect
devreport collect --project .
devreport collect --port 8000
devreport collect --log ./examples/sample.log --tail 50
devreport collect --format markdown --output ./report.md
devreport collect --format json --output ./report.json
devreport collect --preview
devreport collect --output ./report.md --force
python -m devreport collect --help
```

## Пример фрагмента Markdown

```markdown
# DevReport

- schema_version: `1.0`
- tool_version: `0.1.0`

> Автоматическое маскирование неполное: оно не удаляет все секреты. Обязательно проверьте отчёт вручную перед публикацией.

## Система
- ОС: Windows / ...
- Python: 3.11.x
```

Поле `schema_version` в отчёте: **`1.0`**.

## Коды выхода

| Код | Значение |
| --- | --- |
| 0 | Отчёт сформирован (даже при warning/error в проверках) |
| 1 | Внутренняя ошибка или невозможность записать отчёт |
| 2 | Некорректные CLI-аргументы или конфигурация |

Отсутствие Git/Docker/`.env` само по себе не даёт код 1.

## Приватность

- Не собираются hostname, имя пользователя, MAC/IP интерфейсов, полный `sys.executable`, набор переменных окружения процесса.
- Не читаются SSH-ключи, credential stores и домашние каталоги целиком.
- Нет сетевой отправки и телеметрии.
- Таблица соответствий псевдонимов redaction существует только в памяти и не пишется в отчёт.

**Предупреждение:** автоматическое маскирование неполное и не удаляет все секреты (нестандартные имена ключей, свободный текст, неизвестные форматы). Обязательно проверьте отчёт вручную перед публикацией.
